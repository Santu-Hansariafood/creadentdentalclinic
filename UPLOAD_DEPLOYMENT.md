# Upload Deployment Limit

The medical-record upload route accepts files up to `UPLOAD_MAX_FILE_SIZE_MB` per file. The default is 50 MB.

The reverse proxy or hosting platform must allow a request body larger than that value, including multipart overhead. Configure the proxy limit to at least 55 MB (or use the platform's equivalent setting), then restart/redeploy the backend.

Examples:

```nginx
client_max_body_size 55m;
```

If the 413 response is generated by Cloudflare or another edge service before the request reaches Node, changing Express or Multer will not help. Check the response headers and the origin/proxy logs. Upload a file below 50 MB to distinguish the application limit from the edge limit.
