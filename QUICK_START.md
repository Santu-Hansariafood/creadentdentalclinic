# 🚀 Quick Start Guide

## Ports Configuration

- **Frontend (Vite Dev Server)**: http://localhost:25000
- **Backend (API & GraphQL & Socket)**: http://localhost:25001

---

## 🔧 Setup Instructions

### 1. Backend Setup

```bash
cd backend
npm install
npm run dev
```

Backend will run on port 25001 ✅

---

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend will run on port 25000 ✅

---

## 📁 Environment Variables

Both `.env` files are already created and configured for you!

---

## 🎉 Access the App

Open your browser and navigate to: **http://localhost:25000**

---

## 📡 API Endpoints

- **REST API**: http://localhost:25001/api
- **GraphQL Playground**: http://localhost:25001/graphql
- **Health Check**: http://localhost:25001/health

---
